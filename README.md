# GeometrySolver

Браузерный редактор геометрических построений. Первая версия будущего решателя задач на плоскости.

## Запуск

Из корня репозитория:

```sh
python3 -m http.server 8000 --directory web
```

Откройте http://localhost:8000. Сборка и установка зависимостей не требуются.

## Возможности

- Точки, отрезки, бесконечные прямые и окружности по центру и точке.
- Привязка к существующим точкам, предпросмотр построения.
- Автоматические точки пересечения прямых, отрезков и окружностей. Из них можно строить новые фигуры.
- Панорамирование зажатой средней кнопкой, масштабирование колесом относительно курсора.
- Перемещение точек с перестроением связанных объектов.
- Выбор объектов на чертеже и в списке, удаление через Delete.
- Удаление точки удаляет зависимые фигуры.
- Отмена и повтор действий, история построения.
- Автоматическое сохранение в localStorage текущего браузера.

Горячие клавиши: V — выбор, P — точка, S — отрезок, L — прямая, C — окружность, Esc — отмена текущего построения, Ctrl/Cmd+Z — отмена, Ctrl/Cmd+Shift+Z — повтор.

## Развёртывание

Каталог `web/` можно отдавать любым статическим HTTP-сервером (например, Nginx). Все ресурсы локальные, внешние сервисы и серверный API не используются. Встроенный сервер Python предназначен для локальной разработки.

## Дальнейшее развитие

Каталог составных построений, постановка целей и автоматический решатель с раскрываемыми шагами. В текущей версии решатель ещё не реализован.
